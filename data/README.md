# Data

Данные для локальной разработки NITEOS Hunt.

Файлы с демо-данными:

- `products.xlsx` - демонстрационный каталог продукции и цены.
- `target-clients.xlsx` - примеры целевых клиентов и критерии качества.
- `demo-companies.csv` - тестовые компании для экранов охоты и карточек.

Все цены, компании, контакты и объекты в демо-файлах являются вымышленными или обобщенными примерами. Перед использованием продукта в продажах их нужно заменить на реальные данные и источники.
