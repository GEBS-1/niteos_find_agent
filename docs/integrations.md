# Интеграции NITEOS Hunt

Документ фиксирует стартовые предположения по API и ограничениям. Секретные ключи здесь не хранятся.

## Текущий проект

- Telegram-бот уже использует DaData для подсказок и обогащения организаций.
- SQLite используется как локальное хранилище.
- Внешние ключи должны храниться только в `.env` или защищенном окружении.

## Планируемые источники

| Источник | Назначение | Статус для MVP |
| --- | --- | --- |
| DaData | Юридические данные, ИНН, адреса, подсказки компаний | Уже частично используется |
| ФНС / открытые реестры | Проверка статуса юрлица и базовых сведений | Требует адаптера |
| Поиск по web / картам | Сайт компании, фотографии объекта, адрес объекта | Требует адаптера |
| Почта / CRM | Экспорт КП и лидов | После MVP |

## Правила

- Любой внешний источник должен сохранять URL или технический источник данных.
- Ошибка одного источника не должна ломать всю охоту.
- Персональные данные нельзя брать из незаконных или сомнительных баз.
- Все демонстрационные данные должны быть явно помечены.
