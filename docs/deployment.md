# Развертывание NITEOS Hunt

## Текущее состояние

Проект содержит работающий Telegram-бот и вспомогательные скрипты развертывания. Новое ТЗ описывает переход к веб-приложению со сквозным сценарием:

```text
охота -> компания -> проверенные данные -> объект -> визуализация -> КП
```

## Локальная разработка

- Секреты: `.env`.
- Локальная база: `data/niteos.db` или другой путь из конфигурации.
- Демонстрационные материалы: `assets/` и `data/`.

## MVP-развертывание

Для первой веб-версии достаточно:

- FastAPI API-сервера;
- статического или React/Vite фронтенда;
- SQLite;
- локальной встроенной очереди задач;
- серверной генерации PDF из HTML-шаблона.

## Следующий этап

После подтверждения сценария MVP можно переходить на:

- PostgreSQL вместо SQLite;
- Redis/RQ или Celery для очередей;
- объектное хранилище для фотографий и PDF;
- аудит действий пользователей;
- роли и экспорт в CRM.
