# Схема: карточка охоты (LLM oneshot)

Дата фиксации: 2026-09-09. Это разовый контракт логики — что делается, откуда данные, что запрещено.

## Цель

Одна платная LLM-заявка с вебом → черновик → **бесплатная сверка** → короткая финальная проверка → карточка в UI.

Не цель: параллельный «массовый поиск вместо ИИ». ИИ ищет, код **проверяет и выкидывает выдумки**.

## Поток (строго по шагам)

```
[1] Запрос пользователя (фраза + город + count)
        │
        ▼
[2] LLM oneshot (RouterAI, web=true, as_of=сегодня)
    черновик JSON: сайт, адрес, ИНН, руководство, ВК, финансы, фото, people
        │
        ▼
[3] Сброс недоверенного из черновика
    телефоны / почта / ВК / личные контакты people → пусто
    (рандома нет; пустое лучше выдумки)
        │
        ▼
[4] DaData / ЕГРЮЛ по ИНН или названию
    подтверждение юрлица, адрес
        │
        ▼
[5] Финансы: сначала ЗаЧестныйБизнес (последний год ≥2025 при сейчас=2026),
    затем ФНС / Checko; LLM-цифры только если sources.finance = ZCB
        │
        ▼
[6] Официальный сайт
    /contact/  → телефон, email
    /about/management/ → ФИО + должность «как написано сейчас»
    ВК со сайта, если есть
        │
        ▼
[7] ВК-группа
    приоритет: ссылка группы из LLM (поиск ВК) → проверка города
    иначе поиск «название + город + ВК»; /wall|/board → нет
        │
        ▼
[8] Фото фасада под архитектурную подсветку
    LLM-ракурс (фасад с улицы) + Яндекс.Карты / поиск здания
    интерьер / продукция / логотип / сток → нет
        │
        ▼
[9] Финальный gate (короткий, без второго LLM)
    - финансы LLM / абсурдный масштаб → очистить
    - телефон не с сайта → очистить
    - фото не фасад → очистить
    - checks: явные источники по полям
        │
        ▼
[10] Карточка в UI / КП
```

## Источники по полям (правило)

| Поле | Допустимый источник | Нельзя |
|------|---------------------|--------|
| ИНН / юрлицо | DaData, Checko, ЕГРЮЛ | выдумка LLM |
| Руководство | страница сайта «Руководство» | чужие ФИО из поиска без сайта |
| Телефон / email | `/contact/` сайта | LLM, «рандом», info@ без страницы |
| ВК | сайт или поиск+проверка города | тёзка / другой город / wall |
| Финансы | ФНС / Checko / ЗаЧестныйБизнес | LLM |
| Фото | карты/поиск фасада здания | LLM-черновик, товар, интерьер |

## Что смотреть при проверке карточки

1. `checks` — цепочка источников.
2. Телефон/почта: `source` должен начинаться с `сайт:…/contact`.
3. ЛПР: `source` = URL `/about/management/` (или аналог).
4. Финансы: `finance_source` = `fns_bfo` / `checko` / `zachestnyibiznes`, иначе пусто.
5. Фото: URL с `get-altay` (Яндекс.Карты) или явный фасад здания по адресу.

## Известные ограничения

- Если в реестрах нет года ≥2025 (при сейчас 2026), поле финансов **пустое** (не берём 2024 и раньше; не берём цифры LLM вроде «150 млрд»).
- ЗаЧестныйБизнес иногда отдаёт 403 с части IP — тогда Checko/ФНС; если и там нет ≥2025 — пусто.
- ВК без подтверждения города/названия и URL вида /wall|/board не показываем.
- После harden всегда проходит **финальный gate** (очистка мусора).
