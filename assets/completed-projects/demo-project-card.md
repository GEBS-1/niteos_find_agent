# DEMO: пример выполненного проекта

> Демонстрационная карточка. Не является реальным проектом NITEOS.

## Объект

Логистический комплекс, фасад 120 м, территория погрузки 4 500 м2.

## Решение

- архитектурная подсветка фасада;
- промышленное освещение зоны ворот;
- отдельная группа прожекторов для проезда грузового транспорта.

## Результат

- улучшена визуальная читаемость объекта в темное время;
- подготовлен предварительный расчет оборудования;
- сформирован пример КП для тестирования генератора PDF.
