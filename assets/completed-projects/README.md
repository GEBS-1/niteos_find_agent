# Completed Projects

Папка для фотографий, описаний и исходных данных выполненных проектов NITEOS.

Когда появятся реальные материалы, для каждого проекта удобно заводить отдельную подпапку:

```text
completed-projects/
└── project-name/
    ├── before/
    ├── after/
    ├── brief.md
    └── equipment.csv
```
