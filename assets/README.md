# Assets

Материалы для продукта NITEOS Hunt.

Текущие файлы с префиксом `demo` являются демонстрационными заглушками. Их можно использовать для разработки MVP, но перед коммерческим использованием нужно заменить на реальные материалы NITEOS.

## Структура

- `brand/` - логотипы, цвета, шрифты, брендовые правила.
- `buildings/` - фотографии или демонстрационные изображения объектов для теста.
- `completed-projects/` - материалы по выполненным проектам NITEOS.
- `proposal/` - примеры коммерческих предложений и шаблоны.
