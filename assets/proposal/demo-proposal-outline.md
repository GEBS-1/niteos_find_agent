# DEMO: структура коммерческого предложения NITEOS

> Демонстрационные данные. Заменить на настоящий пример КП.

Название компании, адрес объекта, найденные фотографии и подтвержденные источники.

## 2. Предварительная задача

Краткое описание сценария освещения: фасад, территория, въездная группа, складская зона.

## 3. Решение

Подобранные серии светильников, количество, назначение и зона установки.

## 4. Стоимость

Оборудование, монтажные допущения, дополнительные опции, НДС.

## 5. Следующие шаги

Выезд, уточнение размеров, финальный светотехнический расчет, согласование КП.
