# Proposal

Папка для настоящих примеров КП, PDF-шаблонов, Word-шаблонов и иллюстраций, которые должны попадать в коммерческое предложение.

Сейчас здесь лежит текстовая демонстрационная структура КП. Реальный пример КП можно добавить сюда отдельным файлом, например `example-proposal.pdf` или `example-proposal.docx`.
